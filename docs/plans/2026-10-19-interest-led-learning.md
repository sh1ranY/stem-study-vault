# 从兴趣走向理解与独立应用：Study Studio 教学设计提案

日期：2026-10-19。状态：产品与教学设计提案，用户已授权先实现图像处理单元与对应 skill 规则。本文较长期的产品方向不代表全部已经实现，也不代表已经证明学习效果；本轮实际实现及验证在文末单独记录。

本轮示范以 **Computer Science and Electronic Engineering（CSEE，计算机科学与电子工程）** 的图像处理应用为主要情境，同时提供其他专业的应用视角。目标是交付教授与学生可以亲自体验的完整教学单元，再通过不同背景学生的实际使用改进。继续本地试点，保留中英双语、纸笔拍照和文字作答；本次不包含云部署或付费模型批处理。

## 1. 产品要帮助学生发生什么变化

建议定位：帮助高校学生从自己在意的问题出发，建立课程概念之间的联系，获得按当前困难调整的支持，并逐步做到独立解释、应用与应对考试。

学习路径是：**发现值得回答的问题 → 作出预测 → 观察或操作 → 建立解释 → 按需补基础 → 独立应用 → 回看与继续探索**。考试练习与这条路径共享概念和学习证据，也保留直接进入限时复习的入口。

“有吸引力”需要同时回答四个问题：这与我有什么关系；我能在这里做什么；现在的挑战是否能够靠努力跨过去；学会后能解释或完成什么新事情。历史故事、视频和图像可以承担其中一部分，但每项材料都要有明确的教学作用。

希望观察到的持续学习，是学生主动提出下一个问题、愿意尝试新情境、在遇到困难后有办法继续。页面应有自然的完成点和返回入口，不能用停留时长代替学习价值。首次吸引、持续兴趣、概念理解、独立解题和考试表现分别记录。

## 2. 用户故事应具体到一次学习经历

| 学生所处情境 | 希望获得的支持 | 产品需要产生的变化 |
| --- | --- | --- |
| 我对修图感兴趣，却不知道信号与系统有什么用 | 从模糊、边缘、纹理等现象开始 | 学生可以先选问题，再看到所需概念和当前课程位置 |
| 我能理解图像变化，但忘了复数 | 就在当前步骤补回必要基础 | 展开一个能完成的桥接任务，完成后回到原问题 |
| 我会积分，却不理解积分为什么能得到频率成分 | 将运算连接到投影、匹配和抵消 | 换一种解释并要求预测，再检验新的例子 |
| 我已经会基础，希望挑战真实应用 | 跳过重复讲解，处理更复杂条件 | 根据具体表现减少帮助，并允许进入拓展 |
| 我只有二十分钟，或即将考试 | 明确此次能完成的目标 | 提供短任务或复习入口，保留未处理的概念和条件 |
| 我和同学专业不同，但同上一门课 | 看见与各自任务相关的应用 | 共享正确的概念核心，切换应用视角，允许自由跨专业选择 |

专业是推荐情境的线索，不是能力、兴趣或学习方式的替代证据。第一次不要求完成一份长画像问卷；先获得当前目标、语言、可用时间和一个感兴趣的问题，再通过真实学习逐渐了解学生。

## 4. 首个完整单元：为什么照片会模糊，锐化又能恢复多少

### 范围与完成目标

这是一项连接 ELEC270 与图像处理的教学单元，首版限定为**灰度图像、空间频率与简单线性滤波**。主任务为“平滑为什么减弱某些噪声，却也损失边缘和纹理”，锐化的作用与局限作为相邻的短拓展；不将完整图像复原理论塞入首个单元。它不承担一整门计算机视觉课，不以完成滤镜操作等同于掌握全部 Fourier 理论。

学完后希望学生能够：

1. 从一行像素的亮度变化解释空间频率，并区分它与时间频率的单位。
2. 预测平滑对细纹理、边缘及某些噪声的影响，说明高频并不都属于噪声。
3. 把局部加权求和与简单滤波联系起来，计算一个明确的小例子。
4. 用自己的话说明空间域与频域是描述同一处理过程的两种方式。
5. 面对另一幅图或另一组信号，选择处理方式并解释其代价；完成一道对应的课程题。

更深的目标，例如推导 Fourier 系数、理解复指数正交性、推导二维 DFT，分别有独立入口和检验任务，不因学生拖动过图像而自动记为完成。

### 学生看到的完整过程

| 环节 | 屏幕与任务 | 教学目的和证据 |
| --- | --- | --- |
| 进入问题 | 同一幅原创测试图：文字、粗细条纹、斜边和已知噪声；并排显示原图与模糊图 | 选择想保住的细节，形成具体目标；不先显示整章长文 |
| 先预测 | 增大模糊强度时，细条纹、粗条纹和噪声分别会怎样 | 留下预测，避免把拖动滑杆当作理解 |
| 观察与操作 | 控制模糊强度；选定一行，同时显示亮度曲线 | 把图像和一维信号连接；变化由确定的计算产生 |
| 建立概念 | 改变正弦条纹疏密、幅度和相位，观察图像与曲线的对应 | 区分亮度、对比度、空间频率、相位，不混成“清晰度” |
| 解释滤波 | 展示局部加权平均，再连接频率成分受到不同程度影响 | 解释过程和作用条件，保留常量输入、边界处理等检查 |
| 补必要基础 | 可展开“复数与旋转”“这一步为什么要乘再求和”等 | 针对卡点补充；既有快速回顾，也有较完整推导 |
| 工程选择 | 给定含细纹理的噪声图，选择平滑或锐化程度并解释取舍 | 说明减噪可能损失细节，锐化可能增强噪声或产生伪影 |
| 独立检验 | 换一幅原创图或频率组合，提交预测、计算或解释 | 区分独立表现与刚看过解答后的复述 |
| 回到课程 | 完成对应的一维卷积或频率响应题，可拍照或输入文字 | 将应用经验连接到课程符号、推理与考试表达 |
| 继续探索 | 可选采样混叠、混合图像、二维频谱或相机应用 | 留下有意义的下一问；本单元也有明确结束点 |

建议主线可分成几个短阶段保存进度；具体时长应在真实试用后调整，不承诺某个固定分钟数适合所有人。

### 首版数学与演示边界

一维亮度剖面是进入图像处理的桥梁，不能代表所有二维空间关系。可先使用离散滤波

$$y[n]=\tfrac14x[n-1]+\tfrac12x[n]+\tfrac14x[n+1].$$

对常量输入，输出应保持常量；对变化快慢不同的输入，可以计算并比较效果。其频率响应为

$$H(e^{j\omega})=\tfrac14e^{j\omega}+\tfrac12+\tfrac14e^{-j\omega}
=\tfrac12+\tfrac12\cos\omega=\cos^2(\omega/2).$$

这里 $\omega$ 为弧度/样本；对应图像的一行时也可解释为弧度/像素。若用周/像素表示频率，须明确 $\omega=2\pi f$。计算例子以内部像素或明确的延拓条件为准，不能默默改变边缘处理。

二维演示可将该滤波器沿两个轴分别应用，并明确这是一个可分离的二维滤波例子。更广泛的二维滤波、DFT 与频谱显示属于有说明的新内容。FFT 是计算 DFT 的算法；连续 Fourier 变换、离散时间频谱与有限长度 DFT 不能互相冒充。

锐化可以从“当前图像加上部分高频残差”开始：$s=z+\alpha(z-b)$，其中 $z$ 是进入锐化器的图像（可能已经模糊），$b$ 是对 $z$ 再平滑的结果、$\alpha\ge0$。最初的清晰图仅用于对照，不能偷偷作为恢复输入。这个操作增强某些变化，不是对任意模糊的精确求逆。显示裁剪、噪声和模型假设会影响观察结果；不能承诺恢复已经不可辨认的信息。

锐化短拓展还应包含一个可独立解释的反例：在无限序列或偶数长度的周期延拓条件下，均匀灰度 $x_1[n]=c$ 与交替亮暗条纹 $x_2[n]=c+a(-1)^n$，经上述三点平滑都变成 $c$，因为 $H(e^{j\pi})=0$。选择 $c,a$ 使灰度值合法。要求学生说明为什么仅凭相同的模糊结果无法唯一确定哪张原图输入过；不能把增强对比度误认为找回了丢失条纹。主线的平滑学习与这个拓展的完成状态分别记录。

图像处理的频率视角可参考 [CMU 计算机视觉讲义](https://www.cs.cmu.edu/~16385/lectures/lecture3.pdf)。可选拓展“混合图像”有原始研究依据：[Oliva、Torralba 与 Schyns，2006](https://doi.org/10.1145/1141911.1141919)。这些来源用于核对知识和设计思路；本提案没有取得其中图片的再发布授权，首版使用自制测试图。

### 专业应用视角

同一核心内容可以继续连接不同问题：机电学生关心机器人视觉、运动模糊与测量；EEE 学生关心成像传感器、采样与信号链；CSEE 学生关心图像算法实现、计算代价和软硬件配合。这些是可选入口，不是专业之间排他的分配。

更换应用时，变量、设备约束和决策任务也要变化。例如机器人视角需要考虑运动与识别任务，算法视角需要考虑边界、计算量与结果一致性。仅把“电机”换成“相机”不构成个性化。

## 5. 跨课程联系：每条连接都说明它为什么存在

不先建设一张巨大的可视化网络。先让学生在当前卡点看到少数有用的连接及其理由。

| 关系 | 例子 | 产品应如何处理 |
| --- | --- | --- |
| 必要前置 | 使用复指数推导前，需要理解相应的复数运算 | 提供短检查、必要回顾、完整解释与返回原步骤入口 |
| 推导依据 | 欧拉公式将复指数连接到正弦与余弦 | 标注实际使用的等式与推导位置，不只给章节链接 |
| 共同结构 | Fourier 系数与线性代数中的正交投影 | 说明共有结构及不同的对象、内积和条件 |
| 工程应用 | 信号采样知识帮助判断图像采集需求能否成立 | 连接概念、实际变量和约束 |
| 启发性类比 | 用旋转向量解释正弦变化 | 标明类比的解释范围，不把类比当证明 |

用户举的例子中，更准确的名称是**欧拉公式** $e^{j\theta}=\cos\theta+j\sin\theta$。从它到 Fourier 分析还需要周期、正交性、系数提取及相关积分/求和；从 Fourier 级数到变换还涉及适用条件与极限过程，不能只链接一个欧拉公式就声称讲清了变换的来源。[MIT Signals and Systems 教学参考](https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/resources/lecture-9-fourier-transform-properties/)

可把路径显示为：三角函数与复平面 → 欧拉公式 → 正弦与复指数 → 正交性与分解系数 → 频率响应 → 图像滤波。图像的离散与二维扩展另标出来。前置内容若尚未在现有知识库中教授，应创建明确的桥接模块，不虚构其所在的历史课程或周次。

三门课之间目前可以建立以下应用联系，但未核实它们存在正式的课程先修关系：

- **COMP201 软件工程 I ↔ 图像处理项目**：怎样把“照片要清楚、处理要快”写成可验收需求；怎样设计图像输入、滤波与保存模块的接口。
- **COMP207 数据库开发 ↔ 同一项目**：怎样记录原图、处理版本、参数和来源，怎样避免并发编辑覆盖结果。学习 SQL 不需要先掌握 Fourier。
- **COMP201 的并发模型 ↔ COMP207 的事务与锁**：共同关注状态、资源和动作顺序，但 Petri 网、先行图与等待图的含义不同，“有环”的判断不能通用。

## 6. 个性化要调整哪些东西

三层信息分开保存：

1. **学生声明**：当前目标、专业与已有课程、兴趣、语言、时间、设备及交互偏好。可随时修改，不由一次点击永久决定。
2. **实际证据**：针对具体目标的作答、理由、帮助使用、纠正、迁移和延迟复查。记录任务及内容版本；未知仍是未知。
3. **暂定判断与行动**：根据证据推测当前卡点，选择解释或练习，并说明下一项验证。被纠正的证据必须能够撤销相关推断。

例如学生说“我更喜欢图”，但能做代数、不理解频谱，就先用图建立对应关系，再让他回到公式解释。若他误以为高频都是噪声，就用清晰细条纹这个反例来检验并补讲；不因这个错误重写整章。若图形仍不能帮助他完成新题，系统应改变诊断，而不是继续堆图。

“补基础”描述知识缺口；“图形与直觉”“代数与推导”描述解释方式。它们不是互斥的三类学生。新版界面应让学生既能补基础，又能在图形、公式和实际应用之间切换。

学习习惯与方法的支持也应具体：短时间时拆出一个可完成目标；看答案较多时安排新题验证；盲目代公式时练方法选择；容易跳过检查时增加量纲、边界或反例检查。这些支持由实际表现或本人反馈触发，不能把慢、跳过、求助直接解释成懒惰或能力低。

有关偏好匹配的实验没有支持把“视觉/听觉型”作为通用分流依据；它不否认个人差异或无障碍需求。参见 [Rogowsky 等，2015](https://www.apa.org/pubs/journals/features/edu-a0037478.pdf)。

## 7. 内容深度与媒体形式

| 层次 | 必须提供的东西 | 进入方式 |
| --- | --- | --- |
| 现象入口 | 一个值得解释的问题、可观察结果和预测机会 | 可先进入，也允许直接跳往原理或复习 |
| 共同正文 | 定义、适用条件、必要推理、完整示例和独立练习 | 所有人可访问，保留课程标准 |
| 按需补桥 | 当前用到的基础、推导步骤、简短验证和返回点 | 根据实际困难推荐，学生可主动打开 |
| 深入探索 | 更完整证明、非理想模型、实现或新应用 | 说明需要的基础，不强制所有人同时完成 |
| 课程与考试 | 课程符号、方法选择、变式、限时表现 | 保留直接入口，与概念和应用互相链接 |

内容足够深的标准，是学生可以在规定范围内解释“为什么”、重建必要步骤、辨认条件，并在变化后的问题中使用它。文字长度、图片数量、证明数量都不能单独作为标准。

媒体按作用选：静态图支持比较；交互图支持变量变化与因果预测；视频用于需要观察的真实过程；文字与公式支持精确推理；纸笔或代码支持学生自己完成。视频要有观看目的、关键时点、字幕或文字替代，不把整段视频当作已教授内容。

数学曲线、频谱、滤波前后结果与电路等依赖准确关系的图，应由确定的数学或绘图工具生成和核查。生成图片可用于情境插画，但不能承担计算证据。互动不便或需要低动态模式时，应有可读的图表与操作替代。

双语是同一内容的版本：共用概念、活动和证据标识；题干、提示、解答、图注、坐标、交互反馈及必要字幕均对应。切语言不重置题目、不泄露解答、不丢学习位置。国际化还要允许不同课程术语、符号、单位和例子；不能根据国籍猜测能力。

| `references/learning-diagnosis.md` | 将兴趣声明、呈现偏好、具体表现和暂定推断分开；保留证据纠正机制 |
| 新的短参考文档 | 仅在内容规模需要时拆出应用情境、跨课补桥和多媒体验收规范，避免主提示词无限加长 |
| Studio 内容对象 | 增加概念、关系、应用情境、桥接、活动、媒体、版本与来源；先覆盖一个单元 |
| Studio 推荐逻辑 | 根据当前任务与真实证据选下一步，给出简短理由，并允许学生改选 |
| Studio 学习界面 | 增加“探索应用”“查看这里的基础”“展开推导”“转到课程题”，保留系统课程路线 |

Skill 负责约束内容如何生产、教学如何判断；知识库保存核对后的概念与资源；数据库保存活动状态和证据；界面负责让学生真正观察、操作和选择；agent 在这些明确边界内编排下一步。

首版使用现有应用结构即可。少量有类型的概念关系可以先作为明确的数据表或内容文件维护，不因要做“知识网络”就迁移到专用图数据库。通用向量检索也不能取代手工核实的前置关系。

先使用审查过的共同核心、应用情境与局部补讲组件，再根据学生证据做有限调整。全量为每个人实时生成不同教材，会增加数学错误、内容漂移、成本与验证难度；可以在形成可靠检查后逐步开放更大的生成范围。

## 9. 怎么知道它值得学校支持

第一轮只验证可用性与教学可行性：由发起者完成完整单元，再邀请少量不同背景学生。记录哪里愿意继续、哪里退出、哪里产生误解，以及何种帮助实际改变了表现。小样本不用于宣称普遍有效。

| 要回答的问题 | 可观察证据 | 不能替代它的指标 |
| --- | --- | --- |
| 是否觉得这与自己有关 | 能说出用途；主动选择后续问题；本人反馈 | 页面停留时长 |
| 是否理解原理 | 对预测、反例、条件和新图像的解释 | 自评“我懂了”或重复例题 |
| 是否能独立应用 | 未见过的同目标任务，保留帮助记录 | 看完答案后改对同题 |
| 是否保留了学习成果 | 隔一段时间的实际独立复查 | 已安排复习或已读页面 |
| 是否支持课程目标 | 对应的课程题、方法选择与必要的限时任务 | 只完成滤镜小游戏 |
| 是否便于教师使用 | 内容来源、目标映射、错误可纠正、审查负担 | 输出页面数或内容字数 |

后续若比较效果，应使用同样认真打磨的通用教学对照，控制目标、内容和练习机会，考虑顺序与基础差异，并区分“内容本身更好”和“个性化有额外帮助”。正式教育研究的安排应由学校按其程序确认；本提案不将试用同意视作研究或公开学生数据的同意。

## 10. 开发顺序与本轮交付边界

1. **教学样章**：完成图像处理单元的中英正文、任务、答案、前置桥接及原创素材；由独立计算核对关键公式与例题。
2. **可体验的纵向流程**：用当前网站连通预测、图像操作、补桥、独立作答、反馈及课程题；复用既有拍照和学习记录能力。
3. **有限但可解释的适配**：先实现几个具体卡点的教学调整，检验是否有帮助；学生始终可以切换解释或路线。
4. **真实试用与教授评阅**：交付一个完整体验，并给出实际观察到的困难与改动，避免以功能清单替代证据。
5. **扩展课程和情境**：将有效结构迁移到 COMP201 的需求/架构任务、COMP207 的查询/事务任务，按学科分别设计；再扩大跨课关联和自动生成范围。

设计讨论完成后，用户已授权制作现有网站内可完整体验的图像处理单元，并更新 skill。既有课程与翻译继续保留。应用开发使用独立测试数据，不能把演示或测试写入真实学习记录。

## 11. 设计依据及其局限

以下研究支持部分教学机制，不直接证明本产品、AI 个性化或图像处理单元有效。上述具体实现仍需检验。

- **个人意义**：Hulleman 与 Harackiewicz（2009）的高中课堂随机实验发现，让学生自行联系课程与生活，对低成功预期学生的兴趣和成绩有帮助；不能推广为所有学生均有效。[原文](https://sparq.stanford.edu/sites/g/files/sbiybj19021/files/media/file/hulleman_harackiewicz_2009_-_promoting_interest_performance_in_high_school_science_classes.pdf)
- **效果存在差异**：Harackiewicz 等（2016）在大学入门生物课程检验用途写作干预，结果存在群体差异；不能据此按身份预测某个学生的教学方案。[论文入口](https://pubmed.ncbi.nlm.nih.gov/26524001/)
- **学会感与实际学习分离**：Deslauriers 等（2019）在大学物理实验中观察到主动学习提高即时测验表现，却降低主观学会感；不等同于已经验证人机教学的长期效果。[原文](https://www.pnas.org/doi/full/10.1073/pnas.1821936116)
- **节奏与分段**：Mayer 与 Chandler（2001）的动画实验支持学习者控制分段对迁移的帮助，并非所有保持指标都改善，也不证明视频天然优于文字。[原文](https://tecfa.unige.ch/tecfa/teaching/methodo/Mayer_Chandler01.pdf)
- **观看期间的回忆尝试**：Szpunar 等（2013）在短统计视频实验中发现穿插回忆测验减少走神并改善即时学习；不能推断最佳测验频率或学期效果。[原文](https://www.pnas.org/doi/full/10.1073/pnas.1221764110)
- **呈现偏好不等于最佳教学方式**：Rogowsky 等（2015）的文本/音频实验未发现匹配偏好带来的理解优势，研究范围有限；据此避免固定分型，同时保留偏好与无障碍选择。[原文](https://www.apa.org/pubs/journals/features/edu-a0037478.pdf)

素材策略延续既有 IP 讨论：来源、版本、可用范围与授权状态跟随内容和媒体保存；自行改写不自动清除原素材的权利问题。首个公开可演示单元优先采用原创文本与测试图。教授提到的历史图像可作为技术史话题；产品没有必要复制该图片。若确认为 Lena 图像，IEEE 当前投稿政策已明确不再接受含该图的论文；这不是所有教学使用的法律结论。[IEEE 官方说明](https://ieeeaccess.ieee.org/authors/submission-guidelines/)
