# Study Studio: install and use

Study Studio is a local React + FastAPI + SQLite learning app. The repository also contains a separate Codex Skill for building Obsidian course notes. [中文完整说明](README.md) · [Repository and Skill](../../README.en.md)

## Try it without private files or an API key

Download and extract this repository, or clone it. Install Python (3.12 recommended, 3.9+ supported) and Node.js (22.12+ recommended, including npm). Open a terminal in `apps/study-studio`:

```sh
python3 start.py --demo
```

On Windows use `py -3 start.py --demo`. Alternatively double-click `demo.command` on macOS or `demo.cmd` on Windows. If Windows provides only `python`, use `python start.py --demo`.

The launcher installs dependencies, initializes storage, seeds original content for three courses, builds the UI and opens **http://127.0.0.1:5177/**. The first installation needs internet access; prepared reading and answer checks work offline. Keep the terminal open; Ctrl+C stops the server.

Create your own local account with a password of at least ten characters. No invitation is required for the first account. Additional accounts need an invitation generated by the owner in Settings. Select **English** at the top of the page.

Demo mode uses separate `data-demo/` storage and a separate session cookie. It overrides private database settings and disables model calls, even if `.env` contains credentials. No Obsidian vault, university files, cloud account or API key is needed. It contains original starter lessons, not a complete university course.

## A five-minute walkthrough

1. Use the **Course** selector at the top of the sidebar.
2. In **My study plan**, choose **Check your starting point**, or read the notes first.
3. Choose foundations, examples/intuition or rules/reasoning. ELEC270 ramps also have a three-step guided lesson with interactive graphs.
4. Enter your working and key answers. You can upload a JPEG, PNG or WebP photo (up to 10 MB), then manually transcribe it in demo mode.
5. Confirm the transcription and answers before submitting. Report prior answer exposure or external help honestly.
6. Review your saved evidence and export the current course in **Settings & export**.

Drafts autosave. Course switching flushes the answer draft and saves the current lesson note before navigation. Before ordinary lesson navigation, use the note’s save button. Wait for a saved-draft indication before refreshing or closing the page.

| Course | Original checked topics |
|---|---|
| ELEC270: Signals and Systems | Ramp construction; rectangular convolution; Fourier normalisation |
| COMP201: Software Engineering I | Requirements and acceptance; Petri-net firing; boundary-value testing |
| COMP207: Database Development | Joins and COUNT; WHERE/GROUP BY/HAVING; conflict serialisability |

Each topic has diagnosis, practice and review families with up to 24 bounded variants each. These are limited answer checks, not whole-course assessment. Arbitrary SQL, programs, diagrams and free-form proofs are not automatically graded. AI advice cannot establish mastery or long-term retention. The interface, original tasks and demo notes are bilingual; imported materials retain their source language.

## Explore image processing in ELEC270

Choose **Explore image processing** in the sidebar or the ELEC270 home card. A direct link is `/?course=ELEC270&unit=image-filtering`. This original unit is included in normal local mode and demo mode; it needs no private course files.

Follow prediction, the interactive image lab, explanations with optional foundation bridges, four bounded checks, and reflection/course practice. The synthetic grayscale image and its brightness profile use the same calculation. Noise is repeatable; boundary handling and spatial-frequency units are stated. Pixel signals, convolution, Euler's formula, frequency response and recovery limits are available when needed. Explanations, diagrams, controls, questions, hints, solutions and feedback are bilingual.

Your stage, experiment settings, predictions, reflections and answer drafts persist by account. Switching language keeps the same question IDs. Four check families cover local smoothing, frequency/detail, transfer to time signals, and non-unique recovery, with up to eight variants each. Numerical answers and selected reasons are checked locally; free writing is saved, not semantically graded. Help and previous feedback remain recorded, so later same-family variants are treated as supported practice. These limited checks do not certify course mastery or delayed retention.

The unit makes no AI calls. Its final course-practice link opens the existing convolution exercise and paper/photo workflow. Only a separate, explicit request for transcription or AI advice can use a configured model. Personal exports include the unit's activity and answer records. Wait for successful saving before refreshing or closing.

## Normal local mode and optional AI

Run `python3 start.py` (Windows: `py -3 start.py`), or double-click `start.command` / `start.cmd`. Normal mode opens **http://127.0.0.1:8765/** and defaults to `data/`. Existing courses are preserved; only missing courses receive demos.

For real photo transcription and process feedback, copy `.env.example` to `.env` **only if `.env` does not already exist**. Set `OPENAI_API_KEY` and `STUDIO_VISION_MODEL` to a model available to your account that supports images and structured output. Restart normal mode; `--demo` always disables AI. Never place secrets in frontend variables or Git.

Only explicit transcription/feedback actions call the provider. Each operation makes at most one request with no automatic retry; the default cap is 30 calls per account per UTC day, not a monetary budget. API usage may incur charges. You must verify recognised working before submission.

## Import your own course

After initial installation, stop the server. Prepare a course folder with `Weeks/*.md` (nested academic-year folders are supported) and optional `Sources/` attachments. Use filenames such as `Week 01 - Title.md`.

```sh
.venv/bin/python -m backend.pilot.import_course --course COMP201 --course-root "/absolute/path/to/course" --desktop "/absolute/path/to/source-files"
```

On Windows replace `.venv/bin/python` with `.venv\Scripts\python.exe`. Supported codes: `ELEC270`, `COMP201`, `COMP207`. `--desktop` is optional. The alternative `--vault` layout and source environment variables are described in the Chinese README and `.env.example`.

The importer reads originals without modifying them, copies supported attachments into application storage and records content versions. Inspect its warnings, then restart. Importing updates only the selected course. Existing attempts retain their source version.

This supports the project’s Markdown/Wiki-link conventions, not every Obsidian feature. Specified hint/solution callouts are gated, but arbitrary answers in prose or source downloads are not automatically detected. **Importing files does not generate new teaching packs or a question bank.** Automatic checking remains limited to the nine original topics. Use the [Skill](../../skills/stem-study-vault/SKILL.md) to help build broader source-based notes.

## Data, updates and troubleshooting

- Records are private to each local account and filtered by course. Personal exports include only the selected course. Export each course separately before using the account-wide delete action.
- `.env`, `data/`, `data-demo/`, photos and databases are excluded from Git and container builds. Keep backups private. See the Chinese README for SQLite backup/restore commands.
- Stop the old server, update the repository, then rerun the launcher. It refreshes changed dependencies, migrates storage and rebuilds the UI. It refuses an occupied port instead of silently opening an old version.
- Missing Python/npm: install them and reopen the terminal. macOS double-click blocked: run the Python command in Terminal.
- `127.0.0.1` means the current device. This loopback-only app is not accessible from another computer or phone; cloud deployment is a separate future step.
- Windows launch scripts are provided; this iteration was checked locally on macOS and via Linux CI, not on a native Windows machine.

## Developer checks

```sh
.venv/bin/python -m unittest discover -s tests -v
npm run build
python3 start.py --demo --prepare-only
```

Tests use isolated synthetic data and mocked model responses. SQL answer keys are also checked against actual SQLite queries. These tests do not establish live OCR accuracy or learning benefit. See [VALIDATION.md](VALIDATION.md). The legacy prototype remains at `/?prototype=1` and is restricted to the owner after account setup. Cloud configuration is optional; local startup does not deploy or purchase anything.
